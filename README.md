# シーシャノート

シーシャのフレーバーミックスを記録するアプリです。フレーバーを選んでグラム数を入れるだけで、配合の割合が自動で計算されます。「あの日のあの配合」をいつでも再現できます。

公開ページ：https://marin0610.github.io/shisha-note/

## できること

- **ミックス記録**：タイトル・日付・場所と一緒に、フレーバーごとのグラム数を記録。合計グラムと各フレーバーの割合（％）と比率バーが自動で表示されます。
- **フレーバーカタログ**：フルーツ系・清涼系・スイーツ系・ドリンク系・ハーブ/スパイス系の50種以上を収録。検索してタップで追加でき、カタログにないフレーバーは自分で追加できます。
- **味と雰囲気のメモ**：味のメモ（自由記述）と、雰囲気メモ＋雰囲気タグ（リラックス／すっきり／甘い／重め など12種）。
- **評価とお気に入り**：星5段階評価と、お気に入りマーク。
- **探し直し**：キーワード検索、雰囲気タグでの絞り込み、お気に入りだけ表示。記録は編集・削除もできます。
- 最初からサンプルのミックス記録が2件入っています（編集・削除できます）。

## 記録について

- 記録はすべてブラウザの localStorage に保存され、外部に送信されません。
