# シーシャノート

シーシャのフレーバーミックスを記録するアプリです。フレーバーを選んでグラム数を入れるだけで、配合の割合が自動で計算されます。「あの日のあの配合」をいつでも再現できます。

公開ページ：https://marin0610.github.io/shisha-note/

## できること

- **ミックス記録**：タイトル・日付・場所と一緒に、フレーバーごとのグラム数を記録。合計グラムと各フレーバーの割合（％）と比率バーが自動表示。味のメモ・雰囲気メモ＋雰囲気タグ（12種）・星5段階評価・お気に入り。
- **ブランド別フレーバーカタログ（400種以上）**：Al Fakher、Adalya、Starbuzz、Fumari、Afzal、Chaos、Holster、MustHave、Darkside、Azure、Social Smoke、Trifecta（ニコチン入り）と、DeCloud、Soex、Hydro Herbal（ノンニコチン）を収録。各フレーバーに味の系統（フルーツ／清涼／スイーツ／ドリンク／ハーブ・スパイス）とニコチン有無を持ち、ブランド・系統・ニコチン有無・名前で絞り込み検索できます。カタログにないフレーバーは自分で追加も可能。
- **相性サジェスト**：フレーバーを選ぶと「このフレーバーに合う候補」が理由つきで表示され、タップでそのまま配合に追加できます。
- **おすすめミックス**：「お店の定番」（王道ダブルアップル×ミント、ブルーミスト単体、Love 66単体、パンラーズ単体など、作り方＝配合グラム数つき）と「自分のおすすめ」の2段構成。おすすめから1タップで今日の記録に移せて、記録からおすすめへの登録もできます。
- **探し直し**：記録はキーワード（フレーバー名・ブランド名・系統・ニコチン有無でも可）・雰囲気タグ・お気に入りで絞り込めます。

## 記録について

- 記録はすべてブラウザの localStorage に保存され、外部に送信されません。
- フレーバーカタログは各ブランドの販売情報に基づいて作成しています（網羅性・現行販売を保証するものではありません）。
